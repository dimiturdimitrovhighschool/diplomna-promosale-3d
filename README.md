# Техническа иновация
## 3D среда за онлайн оглед и избор на автомобили за Promosale

**Автор:** Димитър Димитров, 12Е клас, Softuni BUDITEL school. **Учебна година:** 2026–2027.

**Ръководител:** Галина Горянова, galina.goryanova@buditel.bg.

**Компания:** Promosale, ЕИК 201766468.

## Цел
Реалистичен 3D оглед на автомобил отвън, отвътре и под капака, с полезна информация за оборудването и документираното състояние. Услугата цели да подпомага предварителния избор на автомобили онлайн.

В архива папката `gotov-proekt` съдържа `01-plan`, `02-prouchvane`, `03-razrabotka`, `04-prilozhenia` и `05-zashtita`. Включени са план, график, източници, концепция, анкета, техническо задание, тестов протокол и бележки за защита. Двата вътрешни ZIP пакета съдържат версии за учебното упражнение, а не отделни GitHub commits.

## Текущ етап
Начален проект, подготвен с помощта на AI, за преглед и допълване от автора. Няма реализиран 3D прототип или проведено изследване. Следва съгласуване на заданието и осигуряване на разрешени данни за един автомобил. Notion връзка не е предоставена.

Указанията за създаване на хранилище в архива отразяват предходния подготвителен етап. Актуалните качвания се виждат в GitHub Commits.
